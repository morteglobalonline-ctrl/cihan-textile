# Kullanılmayan fotoğraflar

Bunlar firmadan gelen ama sitede kullanılmayan baskılı kumaş fotoğrafları.
`public/` içinde tutulurlarsa her yayın paketine ~2.5 MB olarak giriyorlardı,
o yüzden buraya alındı. Silinmediler — kullanmak isteyen `public/fabrics/`
içine geri taşır ve `asset()` ile referans verir.

- `print-navy-floral-swirl.jpg`, `print-suzani-swirl.jpg` — iyi çekimler,
  Compare bölümünü genişletmek için kullanılabilir.
- `print-maple.jpg`, `print-red-floral.jpg`, `print-mandala.jpg`,
  `print-navy-flatlay.jpg` — sonbahar yaprakları ve kürkle stillenmiş,
  tarihi belli oluyor. Kullanmak yerine yeniden çekmek daha iyi olur.
